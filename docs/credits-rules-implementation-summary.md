# 积分扣除规则实施总结

## 一、已完成的更改

### 1. 图片生成积分 ✅
- **旧规则**：1积分/张
- **新规则**：5积分/张
- **修改文件**：`lib/credits/rules.ts`
- **影响**：所有图片生成操作统一扣除5积分

### 2. 订阅计划积分费率 ✅

#### Basic 计划
- **旧规则**：480p和720p都是4积分/秒
- **新规则**：统一按720p费率扣除（15积分/秒）
- **防薅羊毛**：无论用户选择480p还是720p，都按720p费率扣除

#### Pro 计划
- **旧规则**：480p和720p都是5积分/秒，不支持1080p
- **新规则**：统一按1080p费率扣除（24积分/秒）
- **防薅羊毛**：无论用户选择480p、720p还是1080p，都按1080p费率扣除
- **支持分辨率**：更新为支持1080p

#### Studio 计划
- **旧规则**：720p是4积分/秒，1080p是8积分/秒
- **新规则**：统一按1080p费率扣除（24积分/秒）
- **防薅羊毛**：无论用户选择720p还是1080p，都按1080p费率扣除

#### Free 计划
- **旧规则**：480p是4积分/秒，不支持720p
- **新规则**：统一按720p费率扣除（15积分/秒）
- **防薅羊毛**：无论用户选择什么分辨率，都按720p费率扣除
- **支持分辨率**：更新为支持720p

### 3. 充值用户和Free用户 ✅
- **规则**：统一按720p费率扣除（15积分/秒）
- **实现**：在 `deductVideoCredits` 函数中，如果没有订阅计划，统一按720p费率扣除

## 五、防薅羊毛机制说明

### 机制原理
1. **多送积分**：订阅和积分包赠送更多积分，提升用户感知价值
2. **多扣积分**：实际使用时按更高费率扣除，确保盈利70%以上
3. **强制高费率**：订阅用户必须按高分辨率费率扣除，防止低分辨率滥用

### 实现方式
- Basic订阅用户：即使选择480p，也按720p费率（15积分/秒）扣除
- Pro订阅用户：即使选择480p/720p，也按1080p费率（24积分/秒）扣除
- Studio订阅用户：统一按1080p费率（24积分/秒）扣除
- 充值用户和Free用户：统一按720p费率（15积分/秒）扣除

## 六、代码调用示例

### 检查积分余额
```typescript
import { calculateVideoCredits } from '@/lib/subscription/rules';

const requiredCredits = calculateVideoCredits(subscriptionPlan, resolution, duration);
// 注意：此函数会自动应用防薅羊毛机制
// Basic计划会自动按720p费率计算
// Pro/Studio计划会自动按1080p费率计算
```

### 扣除视频积分
```typescript
import { deductVideoCredits } from '@/lib/credits/deduct';

// 订阅用户
await deductVideoCredits(resolution, duration, metadata, subscriptionPlan);

// 充值用户（无订阅）
await deductVideoCredits(resolution, duration, metadata, null, true);

// Free用户
await deductVideoCredits(resolution, duration, metadata);
```

### 扣除图片积分
```typescript
import { deductImageCredits } from '@/lib/credits/deduct';

await deductImageCredits(metadata);
// 自动扣除5积分
```

## 七、注意事项

1. **向后兼容**：所有现有调用 `deductVideoCredits` 和 `calculateVideoCredits` 的代码无需修改，会自动应用新规则

2. **用户提示**：建议在UI中明确告知用户：
   - "Basic订阅用户：所有视频按720p费率扣除（15积分/秒）"
   - "Pro订阅用户：所有视频按1080p费率扣除（24积分/秒）"
   - "充值用户：所有视频按720p费率扣除（15积分/秒）"

3. **积分余额检查**：使用 `calculateVideoCredits` 检查余额时，会自动应用防薅羊毛机制，确保用户有足够积分

4. **元数据记录**：`deductVideoCredits` 会在元数据中记录：
   - `resolution`: 用户选择的分辨率
   - `actualResolution`: 实际扣除费率对应的分辨率
   - `subscriptionPlan`: 订阅计划
   - `isPaidUser`: 是否为充值用户
