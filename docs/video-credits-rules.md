# 视频生成积分扣除规则

## 概述

视频生成积分扣除有两种计算方式：
1. **固定规则计算**：适用于没有订阅计划的用户
2. **订阅计划计算**：适用于有订阅计划的用户（按秒计费）

---

## 一、固定规则计算（`getVideoCredits`）

适用于：**没有订阅计划的用户**或**未提供订阅计划参数时**

### 规则表

| 分辨率 | 时长 | 积分消耗 | 成本（CNY） | 成本（USD） |
|--------|------|----------|-------------|-------------|
| 480p   | 5秒  | 15积分   | ¥3.2        | $0.45       |
| 480p   | 10秒 | 30积分   | ¥6.2        | $0.90       |
| 720p   | 5秒  | 20积分   | ¥3.8        | $0.60       |
| 720p   | 10秒 | 40积分   | ¥7.4        | $1.20       |
| 1080p  | 5秒  | 30积分   | ¥5.2        | $0.90       |
| 1080p  | 10秒 | 60积分   | ¥10.2       | $1.80       |

### 计算逻辑

1. **时长标准化**：
   - ≤ 5秒 → 按5秒计算
   - > 5秒 → 按10秒计算

2. **精确匹配**：
   - 优先查找与分辨率、标准化时长完全匹配的规则
   - 如果找到，直接返回对应的积分值

3. **线性插值估算**（未找到精确匹配时）：
   - 基于相同分辨率的基础规则
   - 计算公式：`积分 = ceil(基础规则积分 / 基础规则时长 × 实际时长)`
   - 例如：720p 7秒视频 = ceil(20 / 5 × 7) = ceil(28) = 28积分

4. **默认值**：
   - 如果无法计算，默认返回 15积分

---

## 二、订阅计划计算（`calculateVideoCredits`）

适用于：**有订阅计划的用户**

### 订阅计划配置

#### Basic 计划
- **支持分辨率**：480p, 720p
- **积分/秒**：
  - 480p: **4积分/秒**
  - 720p: **4积分/秒**
  - 1080p: 不支持

#### Pro 计划
- **支持分辨率**：480p, 720p
- **积分/秒**：
  - 480p: **5积分/秒**
  - 720p: **5积分/秒**
  - 1080p: 不支持

#### Studio 计划
- **支持分辨率**：720p, 1080p
- **积分/秒**：
  - 480p: 不支持
  - 720p: **4积分/秒**
  - 1080p: **8积分/秒**

#### Free 计划（无订阅）
- **支持分辨率**：480p
- **积分/秒**：
  - 480p: **4积分/秒**
  - 720p: 不支持
  - 1080p: 不支持

### 计算公式

```
总积分 = ceil(积分/秒 × 视频时长)
```

### 计算示例

| 订阅计划 | 分辨率 | 时长 | 积分/秒 | 总积分 |
|----------|--------|------|---------|--------|
| Basic    | 480p   | 5秒  | 4       | 20     |
| Basic    | 720p   | 10秒 | 4       | 40     |
| Pro      | 480p   | 7秒  | 5       | 35     |
| Pro      | 720p   | 15秒 | 5       | 75     |
| Studio   | 720p   | 5秒  | 4       | 20     |
| Studio   | 1080p  | 10秒 | 8       | 80     |

---

## 三、优先级规则

在 `deductVideoCredits` 函数中：

1. **如果提供了订阅计划参数**：
   - 使用 `calculateVideoCredits(订阅计划, 分辨率, 时长)` 计算
   - 按秒计费

2. **如果未提供订阅计划参数**：
   - 使用 `getVideoCredits(分辨率, 时长)` 计算
   - 使用固定规则表

---

## 四、其他相关规则

### 图片生成
- **固定消耗**：1积分/张

### 分镜生成
- **固定消耗**：20积分/次

### 分镜场景（图片+视频）
- **基础积分**：1积分（图片）
- **视频积分**：根据视频规则计算
- **总积分** = 图片积分 + 视频积分

---

## 五、代码实现位置

### 核心文件
- `lib/credits/rules.ts` - 固定规则定义和计算函数
- `lib/subscription/rules.ts` - 订阅计划配置和计算函数
- `lib/credits/deduct.ts` - 积分扣除执行函数

### 关键函数
- `getVideoCredits(resolution, duration)` - 固定规则计算
- `calculateVideoCredits(plan, resolution, duration)` - 订阅计划计算
- `deductVideoCredits(resolution, duration, metadata, subscriptionPlan)` - 执行扣除

---

## 六、使用示例

### 示例1：固定规则计算
```typescript
// 生成5秒720p视频（无订阅计划）
const credits = getVideoCredits('720p', 5);
// 返回：20积分
```

### 示例2：订阅计划计算
```typescript
// Pro计划用户生成7秒480p视频
const credits = calculateVideoCredits('pro', '480p', 7);
// 返回：35积分 (5积分/秒 × 7秒 = 35)
```

### 示例3：扣除积分
```typescript
// 有订阅计划
await deductVideoCredits('720p', 10, metadata, 'pro');
// 扣除：50积分 (5积分/秒 × 10秒)

// 无订阅计划
await deductVideoCredits('720p', 10, metadata);
// 扣除：40积分 (固定规则：720p 10秒)
```

---

## 七、注意事项

1. **时长计算**：
   - 固定规则：时长会被标准化为5秒或10秒
   - 订阅计划：按实际时长精确计算（向上取整）

2. **分辨率限制**：
   - 不同订阅计划支持的分辨率不同
   - 生成前需要检查 `isResolutionAllowed(plan, resolution)`

3. **积分余额检查**：
   - 生成前必须调用 `checkCreditsBalance(requiredCredits)` 检查余额
   - 余额不足时不允许生成

4. **重新生成视频**：
   - 在视频编辑器中重新生成视频时，固定扣除 **10积分**（硬编码）
