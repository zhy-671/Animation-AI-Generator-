# 视频积分UI增强方案

## 一、核心需求

1. **用户可以选择**：5秒/10秒时长，480p/720p/1080p分辨率
2. **根据选择计算积分**：按实际时长和强制高分辨率费率计算
3. **防止薅羊毛**：强制使用高分辨率费率
4. **用户体验**：清晰显示实际扣除规则和积分

---

## 二、实施策略

### 策略说明
- **时长**：按用户实际选择计算（5秒、10秒等）
- **分辨率费率**：根据订阅计划强制使用高分辨率费率
  - Basic订阅：统一按720p费率（15积分/秒）
  - Pro订阅：统一按1080p费率（24积分/秒）
  - Studio订阅：统一按1080p费率（24积分/秒）
  - 充值用户：统一按720p费率（15积分/秒）
  - Free用户：统一按720p费率（15积分/秒）

### 计算公式
```
积分 = 强制高分辨率费率 × 用户选择时长
```

---

## 三、UI增强方案

### 1. 分辨率选择器增强

#### 显示规则
- Basic订阅用户选择480p → 显示"将按720p费率扣除"
- Pro订阅用户选择480p/720p → 显示"将按1080p费率扣除"
- Studio订阅用户选择720p → 显示"将按1080p费率扣除"

#### 实现方式
```tsx
<SelectItem value="480p">
  <div className="flex items-center justify-between w-full">
    <span>480p</span>
    {plan === 'basic' && (
      <span className="text-xs text-yellow-500 ml-2">
        (将按720p费率扣除)
      </span>
    )}
    {plan === 'pro' && (
      <span className="text-xs text-yellow-500 ml-2">
        (将按1080p费率扣除)
      </span>
    )}
  </div>
</SelectItem>
```

### 2. 时长选择器增强

#### 显示规则
- 显示每个时长选项对应的积分扣除
- 实时更新积分预览

#### 实现方式
```tsx
<SelectItem value="5">
  <div className="flex items-center justify-between w-full">
    <span>5秒</span>
    <span className="text-xs text-gray-400 ml-2">
      ({calculateCredits(plan, resolution, 5)}积分)
    </span>
  </div>
</SelectItem>
```

### 3. 积分预览组件

#### 位置
- 在分辨率/时长选择器下方
- 在生成按钮上方

#### 显示内容
- 用户选择的分辨率和时长
- 实际扣除费率（如果不同）
- 总积分
- 当前余额和生成后余额
- 警告提示（如果积分不足或费率不同）
