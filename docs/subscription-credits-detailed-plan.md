# 订阅与积分购买详细方案

## 一、核心策略

### 策略说明
1. **多送积分**：订阅和积分包可以赠送更多积分，提升用户感知价值
2. **多扣积分**：实际使用时按更高费率扣除，确保盈利
3. **防止薅羊毛**：订阅用户必须按高分辨率费率扣除，防止低分辨率滥用

## 六、防薅羊毛机制

### 机制说明

1. **Basic订阅用户**
   - 即使选择480p，也按720p费率（15积分/秒）扣除
   - 防止用户用Basic计划薅480p羊毛
   - 用户感知：获得500积分，但实际只能生成33.3秒720p视频

2. **Pro订阅用户**
   - 即使选择480p/720p，也按1080p费率（24积分/秒）扣除
   - 防止用户用Pro计划薅低分辨率羊毛
   - 用户感知：获得1200积分，但实际只能生成50秒1080p视频

3. **Studio订阅用户**
   - 统一按1080p费率扣除
   - 享受最高质量服务

4. **充值用户和Free用户**
   - 统一按720p费率扣除
   - 防止低分辨率滥用

### 用户体验优化

- **多送积分**：提升用户感知价值
- **统一高费率**：确保盈利，防止薅羊毛
- **清晰说明**：在购买页面明确说明扣除规则

function getVideoCreditsRate(userType: 'basic' | 'pro' | 'studio' | 'paid' | 'free', selectedResolution: string): number {
